# 10th Anniversary Website — Vishal ❤️ Sahana

## Run it
Open `index.html` in a browser, or host the folder free on Netlify, GitHub Pages or Vercel (drag & drop the folder).
Music autoplay needs a click, so it starts when Sahana taps "Open Your Love Letter".

## 1. Add your 3 photos
Put your photos in `public/photos/` named exactly:
- `photo1.jpg` – Our First Memory
- `photo2.jpg` – My Favourite Moment With You
- `photo3.jpg` – My Forever Favourite Person
Tip: portrait photos (4:5), about 1000px wide, under 300 KB each load fastest.
Change captions in `index.html` (search "Our First Memory", etc.).

## 2. Add your song
Save a song you have the rights to use as `public/love-song.mp3`.
Royalty-free options: Pixabay Music, YouTube Audio Library, Free Music Archive (check licence).
Or record/produce your own. No file = the site still works silently.

## 3. Personalise the timeline
In `index.html`, find `<!-- 5. TIMELINE -->` and replace every [bracketed placeholder].

## 4. Edit the love letter
Edit the text inside `<div id="letterText">` in `index.html`.
Or open `index.html#edit` and click into the letter to type directly (then copy the text into the HTML to keep it — typing in the browser does not save).

## Colours & fonts
Change the variables at the top of `style.css` (`--maroon`, `--cream`, `--blush`, `--gold`).
